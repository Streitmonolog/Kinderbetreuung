# Security Policy

## Unterstützte Version

Sicherheitskorrekturen werden grundsätzlich für die jeweils aktuelle veröffentlichte
Version vorgenommen.

## Sicherheitslücken melden

Bitte veröffentliche mögliche Sicherheitsprobleme nicht sofort als detailliertes
öffentliches Issue. Nutze, sofern im GitHub-Repository aktiviert, eine private
Security Advisory oder kontaktiere den Maintainer über das GitHub-Profil.

Bitte gib möglichst an:

- betroffene Version
- reproduzierbare Schritte
- erwartetes und tatsächliches Verhalten
- mögliche Auswirkungen

## Lokale Daten

Kinderbetreuung speichert personenbezogene Angaben lokal unter
`%LOCALAPPDATA%\Kinderbetreuung`. Fehlerberichte sollten daher keine echten
Namen, IBANs oder sonstige personenbezogene Inhalte aus Datendateien enthalten.
