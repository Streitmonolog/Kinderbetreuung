# Datenschutz

**Kinderbetreuung** arbeitet lokal auf dem Windows-PC.

## Welche Daten verarbeitet die Anwendung?

Je nach Eingabe können unter anderem folgende Daten gespeichert werden:

- Name des betreuten Kindes
- Namen von Betreuungspersonen
- Betreuungstage und Kalenderwochen
- Fahrtstrecken und Fahrtkostenerstattungen
- Betreuungsentgelte, Stunden und Stundenlohn
- optionale Notizen, Ausflugs- und Dokumentationsangaben
- optional eine IBAN zur eigenen Dokumentation unbarer Zahlungen

## Wo werden die Daten gespeichert?

Die Programmdaten werden lokal im Benutzerprofil unter
`%LOCALAPPDATA%\Kinderbetreuung` gespeichert.

## Netzwerk / Telemetrie

Die Anwendung enthält keine Telemetrie, keine Benutzerkonten und keine Funktion,
die die erfassten Betreuungsdaten automatisch an einen Server des Projekts
überträgt.

Für den XLSX/PDF-Export kann lokal installiertes Microsoft Excel oder LibreOffice
verwendet werden.

## Verantwortung der Nutzer

Nutzer sind selbst dafür verantwortlich, personenbezogene Daten nur in zulässiger
Weise zu verarbeiten, zu speichern, weiterzugeben und zu sichern.
