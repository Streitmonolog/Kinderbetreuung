# Roadmap: Microsoft Store

Ziel ist eine spätere Veröffentlichung von **Kinderbetreuung** im Microsoft Store.

## Phase 1 – GitHub

- öffentliches Repository
- reproduzierbarer Windows-Build
- GitHub Releases
- saubere Lizenz-, Datenschutz- und Sicherheitsdokumentation
- keine persönlichen Testdaten im Repository oder Release

## Phase 2 – Release-Qualität

- vollständige Versionsinformationen in der EXE
- digital signierte Builds
- standardisierter Installer bzw. MSIX-Paket
- automatisierte Build- und Release-Pipeline
- saubere Update-Strategie

## Phase 3 – Store-Vorbereitung

- Microsoft Partner Center / Entwicklerkonto
- App-Namen reservieren
- Store-Beschreibung, Screenshots und Grafiken erstellen
- Datenschutzinformationen prüfen
- Paket/Installer gegen Store-Anforderungen testen
- Zertifizierung durchlaufen

## Paketstrategie

Für das langfristige Ziel wird MSIX bevorzugt vorbereitet. Ein klassischer
Win32-Installer kann als Zwischenschritt weiterhin über GitHub bereitgestellt werden.

## Wichtig

Store-Anforderungen können sich ändern. Vor der eigentlichen Einreichung werden die
zu diesem Zeitpunkt aktuellen Microsoft-Dokumentationen und Richtlinien erneut geprüft.
